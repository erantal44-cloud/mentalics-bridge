# שרת גישור - מנטליקס ↔ רפיד וואן

שרת קטן שמחזיק עוגיית session עדכנית לרפיד וואן, ומספק דוח יומי מובנה (לו"ז + בדיקת גבייה) שהטריגר האוטומטי של המייל הבוקר שולף ממנו.

**נכתב ב-Node.js טהור, בלי שום תלות חיצונית** (npm install לא נדרש כדי להריץ).

## משתני סביבה נדרשים

| משתנה | חובה | ברירת מחדל | הסבר |
|---|---|---|---|
| `ADMIN_SECRET` | כן | - | סוד אקראי וארוך (למשל 32 תווים) - מגן על `/admin` ועל `/report` |
| `RAPID_BASE_URL` | לא | `https://mentalics.rapid-image.net` | |
| `DEPARTMENT_ID` | לא | `1` | |
| `EVENING_CUTOFF_HOUR` | לא | `16` | משעה זו ואילך פגישות "אתמול" נחשבות "ערב" לבדיקת גבייה |
| `PORT` | לא | מוגדר אוטומטית ע"י Render | |

## פריסה ב-Render

1. **Web Service** חדש, מחובר לתיקייה הזו (או ל-repo שמכיל אותה).
   - Build Command: (ריק - אין צורך)
   - Start Command: `node server.js`
   - Environment: Node
2. הוסף את משתנה הסביבה `ADMIN_SECRET` עם ערך אקראי וארוך.
3. אחרי הפריסה, כתובת השרת תהיה משהו כמו `https://mentalics-bridge.onrender.com`.

## שימוש יומיומי

1. היכנס לרפיד וואן כרגיל (`mentalics.rapid-image.net/schedule`), כולל קוד ה-SMS.
2. פתח את `https://<כתובת-השרת>/admin?key=<ADMIN_SECRET>` והדבק את ערך העוגייה (הוראות מלאות בעמוד עצמו).
3. זהו - הטריגר האוטומטי ישלוף דוח עדכני כל בוקר דרך `/report?key=<ADMIN_SECRET>`.

## הערות חשובות

- זהו endpoint פנימי לא-רשמי של רפיד וואן (לא ה-Public API המתועד). הוא יכול להשתנות בלי אזהרה בעדכון עתידי של רפיד.
- העוגייה כנראה תפוג בסופו של דבר (ימים/שבועות) - כשזה קורה, `/report` יחזיר שגיאת `COOKIE_EXPIRED_OR_INVALID` והמייל היומי יציין זאת, ואז פשוט חוזרים על שלב 2.
- שמירת העוגייה היא בקובץ מקומי (`data.json`) - בתוכנית החינמית של Render ייתכן שהדיסק לא נשמר בין הפעלות מחדש של השרת; אם זה קורה בפועל, פשוט מדביקים עוגייה מחדש.
- שדרוג עתידי אפשרי: תוסף Chrome קטן שקורא את העוגייה אוטומטית (עוקף את הצורך בהעתקה ידנית מ-DevTools).
